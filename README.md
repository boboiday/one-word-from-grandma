A one-word entry for the make.fun bounty One Word From Grandma. The program (`main.ts`, Node 22, standard library only) writes one word to `/output/entry.txt`:

> Witchcraft

The word a grandma would text about AI: warm, a little baffled, funny in one word with no context — her explanation for a machine that talks back is that it must be magic. The program is deterministic: it writes the same 10 bytes on every run, with no network access and no secrets.

## Run it

```sh
node main.ts
```
